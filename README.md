# SOUL — Your Peaceful Place

„Un loc în care sufletul tău poate respira.”

Aplicație web instalabilă (PWA) pentru liniște și relaxare. Fără cont, fără build.
Fișierele din rădăcină sunt aplicația: `index.html`, `manifest.webmanifest`, `sw.js`, `icons/`.

Publicată prin GitHub Pages. Pe telefon: deschide adresa în Safari (iPhone) sau Chrome (Android)
și alege „Adaugă pe ecranul principal” / „Instalează aplicația”.
